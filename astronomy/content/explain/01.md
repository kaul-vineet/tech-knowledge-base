# Your astronomy workbench: Python, pinned libraries, Stellarium and offline data — explained

## The intuition
A pipeline is trustworthy only if someone else can run it and get the same numbers. This lesson builds that habit first: one Python version, exact pins, data folders with fixed roles, and a seeded generator so every "random" sky is identical everywhere.

Locally only numpy is needed; Astropy, Skyfield, SciPy and photutils are pinned but run in CI. Stellarium plays the telescope.

**Analogy:** a lockfile plus a fixed test fixture: the pins are the lockfile, seed 42 is the fixture.
Where the analogy breaks: sky data (leap seconds, catalogues) also ages, so later labs add freshness tests.

```
requirements.txt --parse_pins()--> PINS --installed()--> version table
make_folders() --> labs/data/{raw, cache, derived}
default_rng(42) --synthetic_stars()--> same 3 stars on every OS
```

The one thing to remember: if two machines can print different numbers, the result is not yet science.

## Walkthrough: what actually happens when you run it
### Step 1 — check the environment
**You run** `python check_env.py`

**What happens inside** `parse_pins()` reads requirements.txt (stripping CRLF), `installed()` asks `importlib.metadata`, `make_folders()` creates the folders, `synthetic_stars(42)` draws RA and magnitude.

**What you see**
```
  numpy     pin 2.5.3   installed 2.5.3
  astropy   pin 8.0.2   not installed -> runs in CI
data folders: data/raw, data/cache, data/derived
seed 42 stars (RA deg, mag): [(278.6242, 8.97), (157.9962, 2.94), (309.0953, 11.76)]
READY for local labs
```

**What it means / what would look wrong** A different first star means a different numpy generator; nothing later is comparable.

### Step 2 — seeds at work
**You run** `python try_it.py`

**What happens inside** Two unseeded generators use OS entropy; seeds 42 and 43 go through `synthetic_stars()`.

**What you see**
```
unseeded fields equal? False
seed 42 first star: (278.6242, 8.97) | seed 43 first star: (234.8277, 10.39)
```

**What it means / what would look wrong** A neighbouring seed gives an unrelated sky, not a similar one.

### Step 3 — the tests
**You run** `python -m unittest -v`

**What happens inside** Five tests: version, numpy, pins, folders, seeding.

**What you see**
```
Ran 5 tests in 0.218s
OK
```

**What it means / what would look wrong** A pin written `>=` fails the exact-pin test.

## Common confusions
- **Q:** "Astropy is missing, so the lab is broken." — **A:** the line says `runs in CI`; only numpy is required.
- **Q:** "I can fix a typo in data/raw." — **A:** raw is never edited; fixes go to derived.
- **Q:** "Seeds 42 and 43 give similar skies." — **A:** RA 278.6242 vs 234.8277.
