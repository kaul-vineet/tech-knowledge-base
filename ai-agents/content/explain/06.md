# A minimal agent loop — explained

## The intuition
An agent is lesson 5's tool round trip inside a `for` loop: call the model; run any requested tools and append results; repeat. Two exits only: a text answer, or `max_steps` used up.

State is just `messages`. `REGISTRY` is an allow-list (function, needs-approval flag, schema); `execute()` turns every failure into an error *string* for the model instead of a crash.

Analogy: a timeboxed junior engineer: use a tool, read the result, repeat, then hand in an answer or "ran out of time".
Where the analogy breaks: the junior remembers on their own; this agent remembers only what is in `messages`.

```
model(messages) ──text──▶ stop: final_answer
      │tool_calls
      ▼
execute() ─▶ append results ─▶ (loop; after max_steps ─▶ stop: max_steps)
```

The one thing to remember: a loop without a budget and a stop condition is not an agent, it is a bill.

## Walkthrough: what actually happens when you run it
1. **You run** `python agent_loop.py` (budget 5).
   **What happens inside:** the fake returns one tool call per turn. `calculator()` walks the AST (`+ - * /` only, no `eval`).
   **What you see:**
   ```
   step 1: tool  -> calculator({'expression': '17*23'}) = 391
   step 2: tool  -> calculator({'expression': '(120-20)/4'}) = 25.0
   step 3: final -> Final answer: 17*23 = 391; (120-20)/4 = 25.0
   {'answer': 'Final answer: 17*23 = 391; (120-20)/4 = 25.0', 'steps': 3, 'stopped': 'final_answer'}
   ```
   **What it means:** 3 model calls; numbers from code. Expected (not run here): a real model may request both calculations in one turn, giving 2 steps.

2. **Same run**, budget 1.
   **What you see:**
   ```
   …
   stopped: max_steps=1 reached without a final answer
   ```
   **What it means:** a hard stop with an explicit reason, not a hang.

3. **You run** `python -m unittest -v test_try_it_06`.
   **What you see:**
   ```
   observed: {'answer': None, 'steps': 2, 'stopped': 'max_steps'}
   observed: step 3: final -> Final answer: 17*23 = error: action denied by human reviewer; (120-20)/4 = error: action denied by human reviewer
   ```
   **What it means / what would look wrong:** budget 2 is one short of 3. With approval required and the default deny-all approver nothing ran, yet the loop finished because denial is data. A stack trace would mean an error escaped `execute()`.

## Common confusions
**Q:** `max_steps` counts tool calls. — **A:** It counts model calls (loop iterations); one step may contain several tool calls.

**Q:** A denied tool should raise. — **A:** Returning `error: action denied…` lets the model report it (try-it 2).

**Q:** The model computed 391. — **A:** `calculator()` did.
