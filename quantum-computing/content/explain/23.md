# Foundations I: linear algebra for qubits — explained

## The big picture

Every lab from "Qubits and gates in code" onward relied on four facts without proving them: counts always add up to the number of shots; `np.kron` builds multi-qubit states the way Qiskit labels them; some phases matter and some do not; and a Bell pair gives perfectly matching bits. This lesson proves those four facts. Each proof is short, and each has a numerical check in `labs/L500/23-linear-algebra-for-qubits/theorems.py` that you can run in a second. The point is not formalism for its own sake: when a lab output looks wrong, these theorems tell you whether the maths or the code is at fault.

### T23.1 Unitaries preserve inner products, norms and total probability

**In plain words:** a gate can rotate a state but never stretch or shrink it, so probabilities always sum to 1.

**Why it is true (intuition):** a unitary is a rotation in complex space. Rotations preserve lengths and angles; probabilities are squared lengths of components, so their total is the squared length of the whole vector, which the rotation did not change. Skeleton:
1. The bra of `U|ψ⟩` is `⟨ψ|U†`.
2. So `⟨Uφ|Uψ⟩ = ⟨φ|U†U|ψ⟩ = ⟨φ|ψ⟩`.
3. With `φ = ψ`, the norm is preserved.
4. Expanding in any orthonormal basis (Parseval), the probabilities sum to the squared norm, 1.
5. Converse: the polarisation identity rebuilds inner products from norms, so a norm-preserving map is unitary.

**See it in numbers:** `python theorems.py`
```text
  1000 random unitaries (dims 2,4,8,16): max |<Ua|Ub> - <a|b>| < 1e-12: True
  probabilities after the circuit sum to 1.000000
  non-unitary [[1,1],[0,1]] maps |1> to a vector of norm 1.4142 (probabilities would sum to 2.0)
```
The first line tests the theorem on 1000 random cases; the second on a real circuit (H, CX, RY, CP); the third shows what breaks without unitarity: an invertible matrix whose "probabilities" add to 2.0.

**Where it shows up in practice:** "Shots, counts and probability": counts always sum to `shots`. It is also why "Noise models: how Bell and GHZ results degrade" needed density matrices: noise is not a unitary on the state vector.

### T23.2 Tensor-product rules

**In plain words:** applying separate gates to separate qubits is the same as one big Kronecker-product gate, and independent qubits stay independent.

**Why it is true (intuition):** a Kronecker product's entries are products of entries, indexed by pairs. Multiplying two of them sums over pairs, and that sum splits into two independent sums. Skeleton:
1. Write `(A⊗B)_{(i,j),(k,l)} = A_ik B_jl`.
2. Multiply and split the double sum: `(A⊗B)(C⊗D) = AC ⊗ BD`.
3. Apply the same rule to vectors: `⟨a⊗b|c⊗d⟩ = ⟨a|c⟩⟨b|d⟩`.
4. Hence `(U⊗V)†(U⊗V) = U†U ⊗ V†V = I`.

**See it in numbers:**
```text
  mixed-product rule on 200 random 2x2 pairs: max error < 1e-10: True
  |+> (x) |1> = [0.0, 0.7071, 0.0, 0.7071] (basis 00,01,10,11) = qsim H on q1, X on q0: True
```
The last line is the practical one: the *left* factor of `np.kron` is the *highest-numbered* qubit in Qiskit order.

**Where it shows up in practice:** "Qubits and gates in code" (`x_on_q0_of_2` prints `'01'`) and "Same circuit, two frameworks" (Cirq versus Qiskit bit order).

### T23.3 Born rule in any orthonormal basis; global phase is unobservable

**In plain words:** squared overlaps with any orthonormal basis form a probability distribution; multiplying the whole state by a phase changes nothing, but a phase *between* components can.

**Why it is true (intuition):** an orthonormal basis "resolves the identity", so squared overlaps add up to the squared length. A global phase has modulus 1 and factors out of every overlap, and it commutes with every later gate. A relative phase does not factor out. Skeleton:
1. `Σ_k |b_k⟩⟨b_k| = I` (completeness).
2. So `Σ_k p_k = ⟨ψ|ψ⟩ = 1`.
3. `|e^{iθ}|² = 1`, so a global phase changes no `p_k`, now or after any `U`.
4. `|+⟩` and `|−⟩` agree in the Z basis but differ in the X basis.

**See it in numbers:**
```text
  Z basis: |+> gives {'0': 0.5, '1': 0.5}, |-> gives {'0': 0.5, '1': 0.5} (identical)
  X basis (H then measure): |+> gives {'0': 1.0}, |-> gives {'1': 1.0} (relative phase is visible)
```

**Where it shows up in practice:** "Transpiling to a device layout" (`H` becomes `rz·sx·rz` up to a global phase) and "Bernstein–Vazirani as a pattern" (a bias bit is a global phase and is never seen).

### T23.4 Bell-state measurement statistics

**In plain words:** if two people measure a Bell pair at angles `a` and `b`, they agree with probability `cos²(a − b)`, whatever each angle is on its own.

**Why it is true (intuition):** the Bell state "looks the same" from every pair of equal real angles, so only the difference matters. Skeleton:
1. `CX(H⊗I)|00⟩ = (|00⟩ + |11⟩)/√2`.
2. Overlap with `|u_a⟩⊗|u_b⟩` is `cos(a−b)/√2`, so `P(00) = cos²(a−b)/2`; `P(11)` is the same.
3. Mixed outcomes give `sin²(a−b)/2` each.
4. `E = cos² − sin² = cos 2(a−b)`; each marginal stays 1/2.
5. Running the preparation in reverse maps the four Bell states to `00, 01, 10, 11`: a Bell measurement.

**See it in numbers:**
```text
  a = 0.0000, b = 0.3927: P(same) = 0.8536, cos^2(a-b) = 0.8536, E = 0.7071; 20000 sampled shots within 4 sigma: True
  a = 0.3927, b = -0.3927: P(same) = 0.5000, cos^2(a-b) = 0.5000, E = 0.0000; 20000 sampled shots within 4 sigma: True
```
`b = 0.3927` is π/8. In the second row, a maximally entangled pair gives uncorrelated outcomes at a π/4 difference.

**Where it shows up in practice:** "Entanglement with a Bell pair" (the `a = b = 0` case: only `'00'` and `'11'`).

## Worked problems

**P1.** `|ψ⟩ = (|0⟩ + i|1⟩)/√2`, `|φ⟩ = |+⟩`. Find `⟨ψ|φ⟩`, `|⟨ψ|φ⟩|²` and `P(+)`.
1. Write the bra: `⟨ψ| = (1, −i)/√2`. *Why:* a bra is the conjugate transpose; forgetting the conjugate is the classic bug.
2. Multiply: `(1·1 + (−i)·1)/2 = (1 − i)/2`. *Why:* inner product = sum of conjugated products.
3. Modulus squared: `(1/2)² + (1/2)² = 0.5`. *Why:* `|x + iy|² = x² + y²`.
4. By T23.3 the probability of outcome `+` is `|⟨+|ψ⟩|² = 0.5`. *Why:* `|⟨φ|ψ⟩| = |⟨ψ|φ⟩|`.

**P5.** Bell pair; Alice `a = 0`, Bob `b = π/8`. Then `a = π/8`, `b = −π/8`.
1. Difference `a − b = −π/8`. *Why:* T23.4 depends only on the difference.
2. `P(same) = cos²(π/8) = 0.8536`. *Why:* cosine is even, so the sign does not matter.
3. `E = cos(π/4) = 0.7071`. *Why:* `E = cos 2(a − b)`.
4. Second case: difference π/4, `P(same) = 0.5`, `E = 0`. *Why:* `cos²(π/4) = 1/2`; same numbers as the check's second row above.

## Common confusions

- **Q:** Any invertible matrix is a valid gate. — **A:** `[[1,1],[0,1]]` gives norm 1.4142; only unitaries preserve probability.
- **Q:** `|+⟩` and `|−⟩` are the same because Z counts agree. — **A:** The X-basis line separates them completely.
- **Q:** Entangled means always correlated. — **A:** At `a − b = π/4`, `E = 0.0000`.
