### T25.1 Grover success probability and optimal iterations

**In plain words:** each Grover iteration rotates the state by a fixed angle `2θ` toward the marked items, where `sin θ = √(M/N)`; stop after about `(π/4)√(N/M)` steps.

**Why it is true (intuition):** everything happens in the plane of "all marked" and "all unmarked"; oracle and diffusion are two mirrors there, and two mirrors at angle θ rotate by 2θ. Skeleton:
1. Write `|s⟩ = sin θ|w⟩ + cos θ|r⟩`.
2. The oracle reflects about `|r⟩`; diffusion reflects about `|s⟩`.
3. Two reflections = rotation by `2θ`, so after `k` steps the angle is `(2k+1)θ`.
4. `P_k = sin²((2k+1)θ)`; choose `k = ⌊π/(4θ)⌋`, giving `P_k ≥ 1 − M/N`.
5. (Cited) BBBV: no quantum algorithm beats `Ω(√(N/M))` queries.

**See it in numbers:**
```text
  N =  1024, M = 1: best k =  25 (floor(pi/(4 theta)) =  25, (pi/4) sqrt(N/M) =   25.13), P = 0.9995
  N =  1024, M = 4: best k =  12 (floor(pi/(4 theta)) =  12, (pi/4) sqrt(N/M) =   12.57), P = 0.9999
  overshoot, N = 64: P at k = 6 is 0.9966, at k = 12 it is 0.0001 (rotation keeps turning)
```
Quadrupling `M` halves `k` (√ scaling). Doubling `k` past the peak returns almost to zero.

**Where it shows up in practice:** "Small Grover search" (`overshoot`: k = 3 gives 0.3301 for 8 items) and the `sin^2 formula: True` line of its cross-check.

### T25.2 The QFT is unitary and has an O(n^2) circuit

**In plain words:** the QFT matrix is a valid gate, and it needs only about `n²/2` gates for `2^n` amplitudes.

**Why it is true (intuition):** off the diagonal, roots of unity cancel; and the QFT of a basis state factorises into one qubit per output bit. Skeleton:
1. `(F†F)_jk = (1/N) Σ_m ω^{m(k−j)}`: 1 on the diagonal.
2. Off the diagonal, `q^N = 1`, `q ≠ 1`, so the sum is `(1 − q^N)/(1 − q) = 0`.
3. Product formula: `F|j⟩ = ⊗_l (|0⟩ + e^{2πi j/2^l}|1⟩)/√2`.
4. Each factor = one H plus controlled phases from lower qubits; total `n` H, `n(n−1)/2` phases, `⌊n/2⌋` swaps.

**See it in numbers:**
```text
  F^dagger F = I for N = 2 .. 256 (max error < 1e-10): True
  qsim circuit (H, CP, SWAP) equals F for n = 1 .. 5 (max error < 1e-10): True
  n = 5: 5 H + 10 controlled phases + 2 swaps = 17 gates (n(n+1)/2 + floor(n/2)); FFT on 2^n entries ~ n 2^n = 160
```
17 vs 160, but you read one sample, not `2^n` outputs.

**Where it shows up in practice:** "The QFT as a building block": `max |difference|: 0.0` against numpy and the 7-gate drawing for `n = 3`.

### T25.3 Phase estimation

**In plain words:** with `t` counting qubits you read an eigenphase φ to `t` bits; if φ is not exactly a `t`-bit fraction, the nearest one still comes out with probability at least `4/π² ≈ 0.405`.

**Why it is true (intuition):** controlled powers of `U` write `e^{2πiφk}` across the register, the pattern a QFT makes from `|m⟩` when `φ = m/T`; the inverse QFT reads it back. Between grid points the phasors still nearly align for the nearest `m`. Skeleton:
1. Hadamards, then controlled-`U^{2^j}`: register becomes `T^{-1/2} Σ_k e^{2πiφk}|k⟩` (kickback).
2. Inverse QFT: amplitude of `|m⟩` is `(1/T) Σ_k e^{2πik(φ − m/T)}`.
3. Exact grid point: every term is 1, `P = 1`.
4. Otherwise `|a_m| = |sin(πTδ)| / (T|sin(πδ)|) ≥ 2/π` for `|δ| ≤ 1/(2T)`.

**See it in numbers:**
```text
  t = 3, phi = 0.3333: most likely m = 3 (m/8 = 0.3750), P = 0.6878
  t = 3, phi = 0.5625 (halfway between 4/8 and 5/8): P(4) = P(5) = 0.4105
  smallest P(most likely m) over all cases = 0.4054 >= 4/pi^2 = 0.4053: True
```
The halfway case is the worst one, and it still beats the bound.

**Where it shows up in practice:** `solution_period.py` in "The QFT as a building block" (peaks at multiples of `N/r`) is phase estimation's read-out step.

### T25.4 Shor's reduction: factoring reduces to order finding

**In plain words:** if you can find the period `r` of `a^x mod N`, a gcd gives you a factor of `N`, for at least half of all random `a`.

**Why it is true (intuition):** `N` divides `(a^{r/2} − 1)(a^{r/2} + 1)` but neither bracket, so it shares a factor with each. The quantum part only finds `r`, by phase estimation of "multiply by `a`". Skeleton:
1. `r` even and `a^{r/2} ≢ −1 (mod N)`.
2. `N | (a^{r/2}−1)(a^{r/2}+1)`, but divides neither.
3. So `1 < gcd(a^{r/2} − 1, N) < N`.
4. (Cited) random `a` succeeds with probability ≥ 1/2.
5. Continued fractions turn a measured `m/2^t` into `s/r`.

**See it in numbers:**
```text
  N = 21: 6/11 = 0.5455 of the coprime a in [2, N-1] succeed; e.g. a = 2, r = 6, gcd(2^3 - 1, 21) = 7, 21 = 7 x 3
  order finding, N = 15, a = 7, t = 8: outcomes {0: 0.25, 64: 0.25, 128: 0.25, 192: 0.25}; one run recovers r = 4 with P = 0.5000
  N = 21, a = 2, t = 9: a likely outcome m = 427, 427/512 -> continued fraction 5/6 -> r = 6; one run recovers r = 6 with P = 0.3084
```
For `N = 15`, outcomes are multiples of `256/4`; `0` and `128` (giving `s/r` = 0 or 1/2) lose the full `r`, hence `P = 0.5`.

**Where it shows up in practice:** "Resource estimation: logical vs physical qubits and feasibility" costs this algorithm for RSA-2048 (9,025,020 physical qubits in our model).

## Worked problems

**P1.** Grover, `N = 1024`, `M = 1`.
1. `θ = asin(1/32) = 0.03126` rad. *Why:* `sin θ = √(M/N)`.
2. `k = ⌊π/(4θ)⌋ = 25`. *Why:* the largest `k` not past `π/2`.
3. `P_25 = sin²(51θ) = 0.9995`. *Why:* `(2k+1)θ` is just below `π/2`.
4. `P_50 = 0.0002`. *Why:* `101θ ≈ π`, back to the unmarked axis. Classically: up to 1023 queries.

**P6.** Shor's reduction, `N = 21`, `a = 2`.
1. Powers mod 21: 2, 4, 8, 16, 11, 1, so `r = 6`. *Why:* the order is the first power equal to 1.
2. `r` is even; `2^3 = 8 ≢ 20 (mod 21)`. *Why:* both conditions of T25.4.
3. `gcd(7, 21) = 7`, `gcd(9, 21) = 3`. *Why:* each bracket shares one factor.
4. `21 = 7 × 3`; matches the check's `N = 21` line.

## Common confusions

- **Q:** Grover gives exponential speed-up. — **A:** `k ≈ (π/4)√N`, and BBBV says that is optimal: quadratic only.
- **Q:** The QFT computes a whole spectrum in `n²` gates. — **A:** It transforms amplitudes; measurement returns one sample.
- **Q:** One order-finding run always works. — **A:** `P = 0.3084` for `N = 21`; repeat and verify classically.
