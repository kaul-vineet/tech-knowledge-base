# Shots, counts and probability — explained

## The intuition

A quantum program returns a sample, not a value. Each shot prepares the state, measures it and records one bitstring, so every answer is an estimate with an error bar.

The error bar shrinks like 1/√shots: ten times more precision costs a hundred times more shots (and hardware money).

**Analogy:** polling voters. A poll of 10 people can say 60%; a poll of 10,000 lands near the true value.
Where the analogy breaks: here the "true value" is exactly computable for small circuits, so you can check the poll against the census.

```text
H|0> -> exact P = {'0': 0.5, '1': 0.5}
          |
     rng(seed).binomial(shots, 0.5)    (crosscheck_numpy.sample)
          |
   counts -> estimate = count/shots  +/- sqrt(p(1-p)/shots)
```

The one thing to remember: a seed makes a run repeatable, not more accurate; only more shots shrink the error.

## Walkthrough: what actually happens when you run it

1. **You run** `python crosscheck_numpy.py`.
   **What happens inside:** `sample()` draws `binomial(shots, 0.5)` from a seeded numpy RNG; `standard_error()` gives the expected spread.
   **What you see:**
   ```text
   exact: {'0': 0.5, '1': 0.5}
   shots=10     counts={'0': 4, '1': 6}  P('1')~0.600  +/- 0.158
   shots=100    counts={'0': 45, '1': 55}  P('1')~0.550  +/- 0.050
   shots=1000   counts={'0': 513, '1': 487}  P('1')~0.487  +/- 0.016
   shots=10000  counts={'0': 5091, '1': 4909}  P('1')~0.491  +/- 0.005
   seed 2024 twice: {'0': 51, '1': 49} {'0': 51, '1': 49}
   ```
   **What it means:** 0.600 at 10 shots is within one standard error (0.158) of 0.5. A row 5 SE away would mean a bug, not bad luck.

2. **You run** `python shots_lab.py`.
   Expected (not run here): the same four shot sizes from `StatevectorSampler(seed=42)`, different exact counts (its own RNG) but the same shrinking spread; two unseeded runs that usually differ; two seed-2024 runs that match; a text histogram with two similar bars.

3. **You run** `python try_it.py`.
   **What you see:**
   ```text
   try 1  numpy shots=2500 counts={'0': 1294, '1': 1206}  P('1')~0.4824  standard error=0.010
   try 2  numpy seed 2024 {'0': 51, '1': 49}  seed 2025 {'0': 52, '1': 48}  identical=False
   ```
   **What it means:** 0.4824 is 1.8 SE below 0.5, fine. Another seed is simply another stream.

4. **You run** `python -m unittest` → `Ran 10 tests` … `OK (skipped=6)`; the test accepts anything within 5 SE.

## Common confusions

- **Q:** 0.487 at 1000 shots means the circuit is biased. — **A:** The SE is 0.016; 0.487 is under one SE away.
- **Q:** Same seed in Qiskit and numpy gives the same counts. — **A:** Different RNGs; compare distributions, not counts.
- **Q:** Tests should demand exact 500/500. — **A:** They use 5 SE tolerance; exact equality would flake.
