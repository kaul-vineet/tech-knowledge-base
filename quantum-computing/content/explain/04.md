# Entanglement with a Bell pair — explained

## The intuition

Two qubits have four amplitudes, one per bitstring `00, 01, 10, 11`. `H` on qubit 0 puts weight on `00` and `01`. `CNOT(0, 1)` then flips qubit 1 wherever qubit 0 is 1, which moves the `01` weight to `11`. Result: half `00`, half `11`, nothing else.

Each qubit alone is a fair coin, yet the two always agree. No pair of independent coins can do that, which is why the state is "entangled": it cannot be written as (state of q0) × (state of q1).

**Analogy:** a shared random seed: two services that both read the same seed always "randomly" pick the same value.
Where the analogy breaks: no seed exists before measurement, and lesson 24's Bell tests rule out any hidden seed that explains every measurement angle.

```text
|00> --H(q0)--> 0.707|00> + 0.707|01>
     --CX(0,1)-> 0.707|00> + 0.707|11>
                 product test |a00*a11 - a01*a10| = 0.5  (0 would mean NOT entangled)
measure -> only '00' or '11'
```

The one thing to remember: entanglement shows up as correlation that no product of single-qubit states can produce.

## Walkthrough: what actually happens when you run it

1. **You run** `python crosscheck_numpy.py`.
   **What happens inside:** numpy builds `CNOT @ (I ⊗ H) @ [1, 0, 0, 0]`.
   **What you see:**
   ```text
   amplitudes: [0.7071+0.j 0.    +0.j 0.    +0.j 0.7071+0.j]
   probabilities: {'00': 0.5, '11': 0.5}
   ```
   **What it means:** the middle amplitudes (`01`, `10`) are exactly zero. Any non-zero value there means a wrong gate or wrong control/target.

2. **You run** `python bell_lab.py`.
   Expected (not run here): a circuit drawing, `ideal probabilities: {'00': 0.5, '11': 0.5}`, counts with only `'00'` and `'11'`, and `only '00'/'11' seen: True` from `only_correlated()`.

3. **You run** `python try_it.py`.
   **What happens inside:** `_product_test` computes `|a00·a11 − a01·a10|`, zero exactly for product states.
   **What you see:**
   ```text
   swapped_cx  numpy {'00': 0.5, '01': 0.5}  product test 0.0
   x_after_cx  numpy {'01': 0.5, '10': 0.5}  product test 0.5
   ```
   **What it means:** with `cx(1, 0)` the control (q1) is always 0, so nothing happens: 0.0, not entangled. Adding `X` after the CNOT keeps the link but makes it anti-correlated: still 0.5.

4. **You run** `python -m unittest` → `Ran 8 tests` … `OK (skipped=5)`.

## Common confusions

- **Q:** 50/50 on each qubit proves entanglement. — **A:** `swapped_cx` is also 50/50 on q0 but its product test is 0.0.
- **Q:** Entangled means "always equal". — **A:** `x_after_cx` gives `'01'`/`'10'`: always different, still entangled.
- **Q:** `only_correlated()` proves entanglement. — **A:** It checks one basis only; a classical mixture of `00` and `11` passes too. The product test and lesson 24 go further.
