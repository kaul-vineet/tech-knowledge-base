# Set up your quantum environment — explained

## The intuition

Your quantum environment is Python plus Qiskit. Its simulator (`StatevectorSampler`) keeps every amplitude of the state in RAM: ordinary linear algebra on complex numbers.

The lab checks that the pinned versions are installed and that one tiny circuit (`X`, then measure) gives the answer you predict by hand.

**Analogy:** a deployment smoke test: check the image tags, then call one health endpoint whose reply you already know.
Where the analogy breaks: the "service" is a matrix multiplication whose memory doubles with every qubit.

```text
check_env.py: versions vs PINNED --> "OK" / "expected x.y.z"
  |0> --X--> |1> --measure--> transpile(rz,sx,x,cx) --> StatevectorSampler(seed=7), 100 shots
crosscheck_numpy.py: X @ [1,0] = [0,1] --> |amp|^2 --> {'0': 0.0, '1': 1.0}
```

The one thing to remember: a simulator stores 2^n amplitudes, so check small circuits against numpy before trusting bigger ones.

## Walkthrough: what actually happens when you run it

1. **You run** `python crosscheck_numpy.py`.
   **What happens inside:** `X @ KET0` swaps `[1, 0]` to `[0, 1]`; `np.abs(state)**2` is the Born rule.
   **What you see:**
   ```text
   P(X|0>): {'0': 0.0, '1': 1.0}
   expected counts for 100 shots: {'1': 100}
   ```
   **What it means:** the reference answer, no SDK involved.

2. **You run** `python check_env.py`.
   **What happens inside:** `metadata.version()` reads each package, then Qiskit builds, transpiles and samples the circuit.
   **What you see** (no SDKs in this sandbox):
   ```text
   qiskit               missing    expected 2.6.1
   …
   ModuleNotFoundError: No module named 'qiskit'
   ```
   Expected (not run here): with requirements.txt installed every line ends in OK, then `counts: {'1': 100}`.
   **What it means:** "missing" is the check working. A version that differs from the pin is the warning to act on.

3. **You run** `python try_it.py`.
   **What happens inside:** `X @ X @ KET0` returns to `|0>`; `statevector_bytes(n)` is `2**n * 16`.
   **What you see:**
   ```text
   try 1  X twice, numpy counts for 100 shots: {'0': 100}
   try 2  n=30 statevector bytes=17179869184 (16 GiB)
   ```
   **What it means:** gates are reversible, and 30 qubits already need 16 GiB.

4. **You run** `python -m unittest` → **What you see:** `Ran 7 tests` … `OK (skipped=4)`. **What it means:** the 4 skips are SDK tests.

## Common confusions

- **Q:** "missing" means the lab is broken. — **A:** Only the venv is incomplete; the numpy line `P(X|0>)` still proves the maths.
- **Q:** The seed makes results more accurate. — **A:** It only replays the same random draws (lesson 3).
- **Q:** A laptop can simulate 50 qubits. — **A:** 30 qubits already need 16 GiB.
