# Qubits and gates in code — explained

## The intuition

A qubit is a list of two complex amplitudes; a gate is a small matrix that rewrites the list; measuring picks one bit at random, weighted by each amplitude squared.

`X` swaps the amplitudes (a NOT). `H` blends them equally, so a measurement is a fair coin. Apply `H` twice and the blends cancel: certain again. That cancelling (interference) is what algorithms exploit.

**Analogy:** amplitudes are like signed audio waves; two waves can add up or cancel to silence.
Where the analogy breaks: you never hear the wave, only one random click per shot.

```text
|0> = [1, 0]
  X  -> [0, 1]            -> always '1'
  H  -> [0.707, 0.707]    -> '0' or '1', 50/50
  H,H-> [1, 0]            -> always '0' (the minus sign in H cancels)
2 qubits, X on q0 -> index 1 -> printed '01' (q0 is the rightmost character)
```

The one thing to remember: probabilities come from squaring amplitudes, and amplitudes (not probabilities) are what gates add and cancel.

## Walkthrough: what actually happens when you run it

1. **You run** `python crosscheck_numpy.py`.
   **What happens inside:** `apply_1q` builds the operator with `np.kron` (qubit n-1 left, qubit 0 right), applies it, then squares.
   **What you see:**
   ```text
   h              {'0': 0.5, '1': 0.5}
   h_h            {'0': 1.0}
   x_on_q0_of_2   {'01': 1.0}
   ```
   **What it means:** `h_h` is not 50/50: interference made it certain. If you got `'10'` for the last line, your kron order is reversed.

2. **You run** `python gates_lab.py`.
   **What happens inside:** five circuits go to one `StatevectorSampler(seed=7)` call, 1000 shots each.
   Expected (not run here): a text drawing of the `H` circuit, then `x` with only `'1'`, `h` near half and half, and `x_on_q0_of_2` with only `'01'`.
   **What it means:** SDK counts should sit within a few standard errors of step 1.

3. **You run** `python try_it.py`.
   **What happens inside:** `H·X·H` equals `Z`, which only flips the sign of `|1>`; `X` moves to qubit 1.
   **What you see:**
   ```text
   h_x_h         numpy {'0': 1.0}
   x_on_q1_of_2  numpy {'10': 1.0}
   ```
   **What it means:** three gates can be invisible on `|0>`; moving the X moves the `1` left.

4. **You run** `python -m unittest` → **What you see:** `Ran 6 tests` … `OK (skipped=3)`; the skips are the SDK tests.

## Common confusions

- **Q:** `H` then `H` should stay random. — **A:** `h_h {'0': 1.0}`: the second `H` cancels the `'1'` amplitude.
- **Q:** `'01'` means qubit 0 is 0. — **A:** Qiskit prints qubit 0 rightmost, so `'01'` is q0 = 1.
- **Q:** Any circuit with `H` is random. — **A:** `h_x_h` equals `Z`: `{'0': 1.0}`.
