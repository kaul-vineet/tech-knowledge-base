### Two's-complement negation and range
**In plain words** An n-bit pattern means a number in [−2ⁿ⁻¹, 2ⁿ⁻¹−1] if you give the top bit weight −2ⁿ⁻¹. "Flip the bits and add one" negates any number except the most negative one, which maps to itself.

**Why it is true (intuition)** A pattern and its signed value differ by a multiple of 2ⁿ, and n-bit hardware only ever computes modulo 2ⁿ — so it cannot tell signed from unsigned. A number plus its bitwise NOT is all ones, which is −1 mod 2ⁿ; adding one gives 0, so NOT u + 1 is −u.
1. Write the value as v = u − b₍ₙ₋₁₎·2ⁿ, so v ≡ u (mod 2ⁿ).
2. The range holds exactly 2ⁿ consecutive integers, one per residue class: a bijection.
3. u + NOT u = 2ⁿ − 1, so NOT u + 1 ≡ −u.
4. If −x is in range, bijectivity makes that pattern −x's; if x = −2ⁿ⁻¹, then −x is out of range and the pattern 100…0 maps to itself.

**See it in numbers** `python3 foundations1.py`:
```
OK   T1 two's complement: n=8,12,16 exhaustive round-trip + invert-and-add-one OK for 69888 values; -2^(n-1) negates to itself; lab 10 decode_temp == 12-bit decode for all 4096 patterns; stub z=-1024 mg -> 0xFC00; 0xFE0C -> -500
```
69,888 = 2⁸ + 2¹² + 2¹⁶: every pattern at three widths. Lab 10's `decode_temp` agrees with the theorem on all 4,096 12-bit patterns.

**Where it shows up in practice** The `if raw & 0x800: raw -= 4096` line in lab 10; forgetting it gave 231 °C.

### LED series resistor, power balance and duty-cycled battery life
**In plain words** R = (Vs − Vf)/I; supplied power equals resistor plus LED power; and battery life is capacity divided by the *time-averaged* current over the right window.

**Why it is true (intuition)** Voltages around a loop must add up (KVL), and energy is conserved. Averaging current is just charge divided by time — so *which* time you divide by matters.
1. KVL: Vs = IR + Vf ⇒ R = (Vs − Vf)/I.
2. Multiply by I: Vs·I = I²R + Vf·I.
3. Round R *up* to a standard E12 value so I never exceeds the target.
4. Charge in a window: t_on·I_on + (T_w − t_on)·I_off; divide by T_w; life ≈ Q/I_avg.

**See it in numbers**
```
OK   T2 Ohm/KVL/power: 3.3 V, Vf 2.0 V, 5 mA -> R 260 ohm -> E12 270 ohm, I 4.815 mA, P_R 6.26 mW, P_LED 9.63 mW, Vs*I = P_R + P_LED; battery 1250 mAh: 2158.3 h (0.5 mA floor), 9588.4 h (0.05 mA), 9600.5 h if the window is stretched to 3,607,400 ms
OK   T2b lesson 14 cross-check: budget.py life_h 2158.3, range [2158.3, 9588.4] == closed-form t = Q / I_avg
```
1.3 V / 5 mA = 260 Ω; 270 Ω gives 4.815 mA. The 9,600.5 h figure is what you get by dividing by the stub clock (3,607,400 ms) instead of the hour — the bug once fixed in lesson 14.

**Where it shows up in practice** `budget.py` in lesson 14.

### Quantisation noise of an ideal uniform ADC
**In plain words** An ideal N-bit rounding ADC adds error with variance Δ²/12, giving SQNR = 6.02N + 1.76 dB for a full-scale sine — *if* the input wanders across steps.

**Why it is true (intuition)** If the input's position inside a step is random, the error is uniform on ±Δ/2; the variance of a uniform spread of width Δ is Δ²/12.
1. Rounding gives |e| ≤ Δ/2.
2. Assume e ~ U(−Δ/2, Δ/2): mean 0, variance Δ²/12.
3. Full-scale sine power: (2ᴺΔ/2)²/2.
4. Ratio 1.5·2²ᴺ ⇒ 1.76 + 6.02N dB.

**See it in numbers**
```
OK   T3 ADC: 10-bit, 3.3 V -> step 3.2227 mV, RMS error theory 0.9303 mV, measured var/(step^2/12) = 1.0006; full-scale sine SQNR 61.89 dB vs 6.02N+1.76 = 61.96 dB
```
Measured variance is within 0.06 % of Δ²/12; the simulated sine's SQNR is 0.07 dB below the formula.

**Where it shows up in practice** `read_analog()` in lab 9's build task; a constant input breaks the assumption (problem 23.8).

### Average and RMS of PWM
**In plain words** A PWM wave at duty D averages D·V_H, has RMS √D·V_H, and its harmonics sit at multiples of the PWM frequency.

**Why it is true (intuition)** The average is area over period; RMS squares first, so √D. A slow load (eye, motor, RC filter) removes the harmonics and keeps the average.
1. Average: (1/T)·V_H·DT = D·V_H.
2. Mean square: D·V_H² ⇒ RMS √D·V_H.
3. Fourier: |c_k| = V_H|sin(πkD)|/(πk).
4. A low-pass with f_c ≪ 1/T leaves the DC term.

**See it in numbers**
```
OK   T4 PWM: write_analog(511), period 20000 us -> D = 0.49951; average 1.6485 V (D*3.3 = 1.6484), RMS 2.3324 V (sqrt(D)*3.3 = 2.3323), first harmonic 2.1008 V (theory 2.1008)
```
511/1023 = 0.49951; the RMS (2.33 V) is well above the average (1.65 V).

**Where it shows up in practice** Lab 9's dimmer; "2.47 V" for duty 767 was an average, not a level.

## Worked problems
**23.1 — decode 0xFE0C (mg).**
1. 0xFE0C = 65,036 unsigned. *Why:* start from the bit pattern.
2. Top bit set ⇒ negative: 65,036 − 65,536 = −500 mg. *Why:* theorem 1, v = u − 2ⁿ.
3. Check: NOT 0xFE0C = 0x01F3 = 499; +1 = 500. *Why:* negation must give +500.

**23.7 — the 9,600.5 h bug.**
1. Awake = 483 × 20 = 9,660 ms. *Why:* the stated inputs.
2. Over 3,600,000 ms: I_avg = (9,660·30 + 3,590,340·0.05)/3,600,000 = 0.13037 mA. *Why:* theorem 2 with T_w = one hour.
3. Life = 1,250/0.13037 = 9,588.4 h. *Why:* Q/I_avg.
4. 9,600.5 h needs T_w = 3,607,400 ms: the final 8 s Deep Sleep ran the clock 7.4 s past the hour. *Why:* the window must match the counted wake-ups.

## Common confusions
**Q:** 0x800 in 12 bits is +2048. — **A:** It is −2048, the one value that negates to itself.

**Q:** Averaging always beats quantisation. — **A:** Only with noise or dither; a constant input rounds the same way every time.

**Q:** PWM power follows the average voltage. — **A:** It follows D (the RMS² ∝ D), not (D·V_H)².
