# Foundations I: probability and stochastic processes for simulation — explained

## The big picture

Every applied lab leaned on four facts without proving them. "Monte Carlo: estimate a project's completion time" trusted that an average of many samples settles down (law of large numbers) and that ±1.96·s/√N is a 95% interval (central limit theorem). "Discrete-event simulation: a single-server queue" drew gaps with `expovariate` because Poisson arrivals have exponential gaps. "Resources and queues: c desks, one line, Erlang C" and "Is the model right? Verification vs validation" compared simulations with queue formulas that come from stationary distributions. This lesson proves those four facts and runs a numerical check for each, so you know exactly which assumption each lab depends on — and what breaks when it fails.

### Theorem 23.1 - Weak law of large numbers (Chebyshev proof)

**In plain words** — the sample mean of uncorrelated draws with finite variance gets close to the true mean, with probability approaching 1 as n grows.

**Why it is true (intuition)** — averaging cancels independent errors; the spread of a mean shrinks like 1/n in variance, so large deviations become rare. Skeleton:
1. Markov: for Y ≥ 0, Y ≥ a·1{Y ≥ a}, so P(Y ≥ a) ≤ E[Y]/a.
2. Apply it to Y = (mean − μ)², a = ε².
3. Var(mean) = σ²/n because the covariances vanish.
4. So P(|mean − μ| ≥ ε) ≤ σ²/(nε²) → 0.

**See it in numbers** — `python t1_wlln.py` (Exponential(1), ε = 0.2, 10,000 means per n):
```
n      Chebyshev bound  observed P(|mean - 1| >= 0.2)
25     1.0000           0.3220
100    0.2500           0.0427
400    0.0625           0.0003
1600   0.0156           0.0000
```
The bound always holds (0.0427 ≤ 0.25) but is loose — it uses only the variance, not the shape. The observed probability collapses much faster than 1/n because of the next theorem.

**Where it shows up in practice** — lesson 2's mean converging to 17.333 days.

### Theorem 23.2 - Central limit theorem (Lindeberg-Levy)

**In plain words** — a standardised sum of iid finite-variance terms looks normal for large n, whatever the terms' distribution.

**Why it is true (intuition)** — near zero every characteristic function looks like 1 − s²/2; raising it to the n-th power erases everything except the variance. Skeleton:
1. Standardise Y = (X − μ)/σ.
2. Its characteristic function is 1 − s²/2 + o(s²).
3. Independence: the sum's function is φ(t/√n)ⁿ → e^(−t²/2).
4. Lévy's continuity theorem turns that into convergence in distribution.

**See it in numbers** — `python t2_clt.py`:
```
n     P(Z_n <= 1.96)  KS distance to N(0,1)  skewness 2/sqrt(n)
1     0.9482          0.1587                 2.000
16    0.9631          0.0324                 0.500
256   0.9728          0.0121                 0.125
exact P(Z <= 1.96) = 0.9750; KS noise floor for 20,000 draws ~ 0.0096
```
The coverage approaches 0.9750 and the distance shrinks with the skewness (Berry–Esseen's O(1/√n)). Skewed inputs converge slowly: at n = 16 a nominal 97.5% bound covers 96.3%.

**Where it shows up in practice** — every t-interval in "Warm-up, replications and confidence".

### Theorem 23.3 - Poisson process has exponential inter-arrival times

**In plain words** — if arrivals are independent, steady and one-at-a-time, the gaps between them are exponential with mean 1/λ, and memoryless.

**Why it is true (intuition)** — "no arrival yet" must decay at a constant rate, because each instant is a fresh, identical chance. Skeleton:
1. P₀(t + h) = P₀(t)(1 − λh + o(h)) by independent, stationary increments.
2. So P₀′ = −λP₀, P₀(t) = e^(−λt).
3. P(T₁ > t) = P₀(t): exponential.
4. Restart at each arrival: later gaps are iid.

**See it in numbers** — `python t3_poisson.py` builds the process from Bernoulli(λ·dt) cells, never drawing an exponential:
```
mean gap 0.5025 (theory 1/lam = 0.5000); var 0.2550 (theory 1/lam^2 = 0.2500)
P(T > 1.0) observed 0.1375 theory exp(-lam t) = 0.1353
memoryless: P(T > 1.5 | T > 0.5) = 0.1411 vs P(T > 1.0) = 0.1375
N(1) per unit interval: mean 1.9886 var 2.0237 (Poisson: both = lam = 2.0)
```
The exponential *emerges* from the definition; the conditional probability matches the unconditional one (memorylessness); counts have mean ≈ variance, the Poisson signature.

**Where it shows up in practice** — `expovariate(LAM)` in lesson 3.

### Theorem 23.4 - Stationary distributions; the M/M/1 queue from birth-death balance

**In plain words** — a well-behaved chain forgets its start and settles into one distribution; for a birth–death queue, flow balance across each cut gives it in closed form.

**Why it is true (intuition)** — in steady state, the rate of crossing from n to n + 1 must equal the rate back. Skeleton:
1. (a) Finite, irreducible, aperiodic ⇒ unique π, rows of Pⁿ → π (Perron–Frobenius; cited and checked).
2. (b) Cut balance: λπₙ = μπₙ₊₁.
3. So πₙ = (1 − ρ)ρⁿ, L = ρ/(1 − ρ).
4. Little's law: W = L/λ = 1/(μ − λ).

**See it in numbers** — `python t4_birth_death.py`:
```
(a) pi from pi P = pi : [0.2439 0.4634 0.2927]
    simulated 200,000 : [0.2457 0.4633 0.2909]
    (1-rho) rho^n    0.2000 0.1600 0.1280 0.1024 0.0819  4.000
    CTMC simulation  0.2003 0.1612 0.1285 0.1025 0.0823  3.919
    Little's law: W = L / lam = 5.000 = 1/(mu - lam) = 5.000
```
Three methods agree on π; the simulated L (3.919) is a little low because long busy periods make it converge slowly.

**Where it shows up in practice** — the 4.0-minute M/M/1 reference in lessons 3 and 6 is W − 1/μ = 5 − 1.

## Worked problems

**23-P2.** Exponential service, σ² = 1. (a) Chebyshev n for P(|mean − 1| ≥ 0.1) ≤ 0.05; (b) CLT n for half-width 0.1.
1. Set σ²/(nε²) ≤ 0.05 — *why:* that is Theorem 23.1's bound. n ≥ 1/(0.05 × 0.01) = 2,000.
2. Set 1.96σ/√n ≤ 0.1 — *why:* the CLT interval. n ≥ (19.6)² = 384.16, so 385.
3. *Why the gap:* Chebyshev must hold for the worst distribution with variance 1; the CLT uses the near-normal shape of the mean. t1's numbers show the same looseness.

**23-P7.** M/M/1, λ = 0.9, μ = 1.
1. ρ = 0.9 — *why:* every formula is in ρ.
2. L = ρ/(1 − ρ) = 9; W = 1/(μ − λ) = 10 min — *why:* Theorem 23.4 then Little's law.
3. Lq = ρ²/(1 − ρ) = 8.1; P(N ≥ 5) = ρ⁵ = 0.5905 — *why:* the geometric tail sums to ρ⁵.
4. At λ = 0.8, W = 5: +12.5% load doubles W — *why:* the pole at ρ = 1 (lesson 3's 0.88 run).

## Common confusions

**Q:** The LLN says my CI is right. — **A:** The LLN gives convergence; the *interval* needs the CLT (and finite variance).

**Q:** Exponential gaps are a modelling choice. — **A:** t3 never draws one — they follow from independent, steady arrivals.

**Q:** Stationary means the queue length stops changing. — **A:** The *distribution* is fixed; the CTMC still wanders (L = 3.919 over a finite run).
