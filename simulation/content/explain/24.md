# Foundations II: numerical methods - truncation error, order, stability, stiffness and floating point — explained

## The big picture

The time-stepped labs produced numbers this lesson now explains. In "Time-stepped physics: a parcel dropped from a drone", Euler's error shrank exactly 10x when dt shrank 10x, and RK4's error *grew* as dt shrank. In "ODE solvers in practice: adaptive steps, tolerances, stiffness", an explicit solver took 3,027 steps on a smooth signal while backward Euler took 1,000 larger ones. "Calibration: fit to data, validate on data you did not fit" computed its Jacobian with a finite-difference step of 1e-6 — a choice floating point dictates. Four theorems explain it: order, RK4's accuracy, stability, and round-off.

### Theorem 24.1 - Explicit Euler: local error O(h^2), global error O(h)

**In plain words** — one step misses by ~h²; N = T/h steps add up to ~h.

**Why it is true (intuition)** — Euler follows the tangent; the curve bends away by about y″h²/2. Early errors are carried forward but, with Lipschitz f, grow at most exponentially in *time*, not step count. Skeleton:
1. Taylor with remainder: one exact-start step misses by τ = (h²/2)y″(ξ).
2. Error recursion: |eₙ₊₁| ≤ (1 + hL)|eₙ| + Mh²/2.
3. Unroll the geometric sum: |eₙ| ≤ (Mh²/2)·((1 + hL)ⁿ − 1)/(hL).
4. Use 1 + x ≤ eˣ: |eₙ| ≤ (hM/2L)(e^(L(tₙ−t₀)) − 1) = O(h).

**See it in numbers** — `python t1_euler_order.py` on y′ = y − t² + 1:
```
h         local err   ratio  global err   ratio  observed order
0.10000   7.415e-03   3.95  2.420e-01   1.82  0.862
0.01250   1.170e-04   3.99  3.321e-02   1.97  0.980
0.00625   2.928e-05   4.00  1.672e-02   1.99  0.990
```
Halving h cuts the local error 4x (h²) and the global 2x (h); the observed order approaches 1.

**Where it shows up in practice** — lesson 4's +1.47 / +0.147 / +0.0147 m.

### Theorem 24.2 - Classical RK4 is fourth order

**In plain words** — RK4's four weighted slopes reproduce the Taylor series of the true step up to h⁴, so global error falls 16x per halving.

**Why it is true (intuition)** — each extra slope sample corrects the previous one's curvature error; the 1-2-2-1 weights match all terms up to h⁴. Skeleton:
1. Write the eight order conditions on the tableau (b, c, A).
2. Check them exactly in rational arithmetic.
3. On y′ = λy one step multiplies by R(z) = 1 + z + z²/2 + z³/6 + z⁴/24.
4. e^z − R(z) = z⁵/120 + …: local O(h⁵), global O(h⁴).

**See it in numbers** — `python t2_rk4_order.py`:
```
(0) order conditions satisfied: 8/8 (…)
(a) z = -0.130: RK4 step = R(z) to 0e+00; e^z - R(z) = -3.028e-07; z^5/120 = -3.094e-07
(b) h         global err   ratio   observed order
    0.10000   6.990e-06    15.59   3.962
    0.01250   1.742e-09    15.96   3.996
```
The step equals R(z) exactly, the residual matches z⁵/120, and the ratio approaches 16.

**Where it shows up in practice** — lesson 4's round-off-level RK4 error; the co-simulation room's RK4 substeps.

### Theorem 24.3 - Absolute stability of explicit Euler; stiffness

**In plain words** — on a decaying problem, explicit Euler only decays if |1 + hλ| < 1, i.e. h < 2/|λ|; implicit Euler decays for any h.

**Why it is true (intuition)** — each explicit step multiplies by (1 + hλ); too large a step overshoots zero by more than it started with, and that compounds. Skeleton:
1. yₙ = (1 + z)ⁿy₀ with z = hλ.
2. Decay iff |1 + z| < 1; for real λ < 0, h < 2/|λ|.
3. Implicit: yₙ = (1 − z)⁻ⁿy₀; |1 − z| > 1 whenever Re z < 0.
4. RK4's real-axis limit is where |R(z)| = 1: −2.785.

**See it in numbers** — `python t3_stability.py`:
```
    h = 0.039  |1 + h lam| = 0.950  |y_200| = 3.505e-05
    h = 0.040  |1 + h lam| = 1.000  |y_200| = 1.000e+00
    h = 0.041  |1 + h lam| = 1.050  |y_200| = 1.729e+04
(b) RK4 real-axis stability limit: z = -2.7853 (explicit Euler: -2)
    explicit Euler h = 0.0021  steps   952  error 2.673e+33
    implicit Euler h = 0.1    steps    20  error 1.923e-05
```
A 5% change in h switches decay to explosion. On the stiff problem the smooth answer cos t is irrelevant: λ = −1000 sets the limit.

**Where it shows up in practice** — lesson 9's RC filter and lesson 15's 313 s communication-step bound (the same |1 − amplification| argument for a delayed loop).

### Theorem 24.4 - IEEE 754 rounding model and its consequences

**In plain words** — every float operation is exact up to a relative error u = 2⁻⁵³; subtracting close numbers magnifies that error, and finite differences trade truncation against round-off.

**Why it is true (intuition)** — binary64 has 53 significant bits; rounding moves a value by at most half a gap. Skeleton:
1. Spacing in [2ᵉ, 2ᵉ⁺¹) is 2^(e−52), so |fl(x) − x| ≤ u|x|.
2. IEEE requires correct rounding of +, −, ×, /, √.
3. Cancellation: a − b keeps the absolute error but shrinks the value.
4. Forward difference: (h/2)|f″| + 2u|f|/h, minimised near √u scale.

**See it in numbers** — `python t4_floating_point.py`:
```
machine epsilon 2.220446049250313e-16 = 2^-52; unit roundoff u = 1.1102230246251565e-16
0.1 + 0.2 == 0.3: False; ten x (acc += 0.1) = 0.9999999999999999; math.fsum = 1.0
cancellation: (1 - cos x)/x^2 at x = 1e-8 -> 0.0; stable 2 sin^2(x/2)/x^2 -> 0.5
    h = 1e-07  error 1.40e-07
    h = 1e-13  error 4.56e-04
    steps 1,000,000  float32 error 2.57e-05  float64 error 1.84e-07
```
The naive formula returns 0.0 for a true 0.5 — total cancellation. Shrinking h below 1e-7 makes the derivative *worse*. float32 stops improving after ~10⁴ steps.

**Where it shows up in practice** — lesson 4's RK4 error growing from 1e-14 to 1e-12 with more steps.

## Worked problems

**24-P3.** y′ = y − t² + 1, h = 0.1: compute the Theorem 24.1 bound at T = 2.
1. L = |∂f/∂y| = 1 — *why:* the Lipschitz constant controls error growth.
2. y″ = 2 − 0.5eᵗ, so M = max|y″| = 0.5e² − 2 = 1.695 — *why:* the bound needs the worst curvature on [0, 2].
3. Bound = (0.1 × 1.695 / 2)(e² − 1) = 0.5413 — *why:* plug into hM/(2L)·(e^(LT) − 1).
4. Measured 0.2420 (t1, h = 0.1) — *why it is smaller:* the bound assumes every error adds in the worst direction.

**24-P6.** y′ = −1000(y − cos t) − sin t on [0, 2].
1. λ = −1000, so h ≤ 2/1000 = 0.002 — *why:* Theorem 24.3.
2. N = 2/h ≥ 1,000 steps — *why:* the interval length over the largest stable h. t3: 952 steps explode, 1,053 are fine.
3. Implicit Euler with h = 0.1: 20 steps, error 1.923e-05 — *why it can:* A-stable, so only accuracy limits h.

## Common confusions

**Q:** Smaller h is always more accurate. — **A:** Below ~1e-7 the forward difference gets worse (4.56e-04 at 1e-13).

**Q:** Stability is about accuracy. — **A:** h = 0.041 vs 0.039 is a tiny accuracy change but a 10⁹-fold difference in |y₂₀₀|.

**Q:** Implicit Euler is accurate because it is stable. — **A:** It is still first order; A-stability only guarantees decay.
