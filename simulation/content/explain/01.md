# Set up your simulation workbench — explained

## The intuition

A simulation turns random numbers into an answer. If you cannot get the same random numbers back, you cannot rerun a result, debug it or compare two designs fairly. So the workbench is an interpreter, a *seeded* random generator and a few pinned libraries.

A seed is the starting state of a pseudo-random generator, which is a deterministic function: same seed in, same stream out. "Random" means "passes statistical tests", not "unpredictable".

Analogy: a seed is a git commit hash for randomness — quote it and anyone checks out the same stream.
Where the analogy breaks: a different algorithm (Mersenne Twister vs PCG64) gives a different stream from the *same* seed.

```
requirements.txt ──> check_env.py ──> "numpy installed / simpy: runs in CI"
seed 42 ──> default_rng(42) ──> PCG64 ──> 0.773956, 0.438878, ...
seed 42 ──> default_rng(42) ──> PCG64 ──> 0.773956, 0.438878, ...  (identical)
```

The one thing to remember: a result you cannot rerun from a recorded seed and version is not a result yet.

## Walkthrough: what actually happens when you run it

1. **You run** `python check_env.py`.
   **What happens inside:** `parse_pins()` reads `requirements.txt` (stripping CRLFs), `installed()` asks `importlib.metadata` for each version, `seeded_draws(42)` builds two fresh generators.
   **What you see:**
   ```
   Python 3.12.15 on Linux x86_64 | CPU cores: 1
     numpy  pin 2.5.3   installed 2.5.3
     simpy  pin 4.1.2   not installed -> runs in CI
   …
   seed 42 -> [0.773956, 0.438878, 0.858598]
   seed 42 -> [0.773956, 0.438878, 0.858598] (identical = reproducible)
   READY for local labs
   ```
   **What it means:** only numpy is needed locally; SimPy, SciPy and Mesa equivalents run in CI. Two different lists would mean hidden global state.

2. **You run** `python try_it.py`.
   **What happens inside:** two *unseeded* generators take OS entropy; then `random.Random(42)` and `default_rng(42)` each draw once.
   **What you see:**
   ```
   unseeded equal? False
   random.Random(42): 0.639427 | numpy default_rng(42): 0.773956
   ```
   **What it means:** a seed is meaningless without the algorithm. Record both.

3. **You run** `python -m unittest -v`.
   **What you see:** `Ran 5 tests in 0.374s` … `OK`.
   **What it means:** version, exact pins, CRLF parsing and the seeded draw all hold.

## Common confusions

**Q:** Seeding makes results less random. — **A:** The stream is statistically the same; the seed makes it *repeatable*. Use different seeds for independent replications.

**Q:** Seed 42 is seed 42 everywhere. — **A:** `0.639427` vs `0.773956` in step 2.

**Q:** I need SimPy to start. — **A:** `READY for local labs` prints with numpy alone.

2. A colleague reports "mean 17.3" with no seed or numpy version. What can't you do?
